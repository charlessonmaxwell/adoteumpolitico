# Story 2.0 — Base do site

**Épico:** 2 · **Status:** Pronta · **Depende de:** 1.5

## Tarefas
1. Astro (geração estática) em `site/`, no mesmo pacote do pipeline
2. Leitura dos dados de `DADOS_DIR` (clone da branch `data`); dados simulados em `site/fixtures/` para desenvolvimento e testes
3. Identidade visual "extrato do mandato" (tokens de cor e tipografia em um arquivo)
4. Comando `pnpm site:build` e `pnpm site:dev`

## Critérios de aceite
- CA1: build com os dados simulados roda no CI
- CA2: nenhuma cor associada a partido (vermelho, azul, verde-amarelo, laranja) na paleta
