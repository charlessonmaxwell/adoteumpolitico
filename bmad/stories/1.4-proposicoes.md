# Story 1.4 — Coletar projetos apresentados

**Épico:** 1 · **Status:** Concluída (28/10/2026) · **Depende de:** 1.1

## Tarefas
1. Câmara: arquivos anuais `arquivos/proposicoes/json/proposicoes-AAAA.json` + `arquivos/proposicoesAutores/json/proposicoesAutores-AAAA.json` (2023 até o ano atual). ~~`/proposicoes?idDeputadoAutor`~~ descartado em 28/10: não traz situação nem autor/coautor (exigiria 100 mil+ chamadas/dia)
2. Senado: `/processo?codigoParlamentarAutor={cod}`, só apresentadas a partir de 01/02/2023 (a API devolve o histórico inteiro)
3. Modelo `Proposicao`: `id`, `casa`, `tipo`, `numero`, `ano`, `ementa`, `situacao`, `dataApresentacao`, `autoria` (autor|coautor), `categoria`, `urlFonte`
4. Campo `categoria`:
   - `legislativa`: PL, PLP, PEC, MPV, PDL
   - `homenagem`: ementa contendo "denomina", "institui o Dia", "declara patrono", "inscreve no Livro dos Heróis" (lista configurável)
   - `procedimental`: REQ, RIC, EMC, DTQ e demais tipos de tramitação
5. ~~Coleta incremental~~ dispensada: com arquivos em lote, a coleta completa custa ~8 downloads + 81 chamadas

## Critérios de aceite
- CA1: totais do perfil contam só `legislativa`; `homenagem` e `procedimental` exibidos separados
- CA2: lista de palavras de `homenagem` fica em arquivo de configuração, não no código
- CA3 (revisado em 28/10): Câmara baixa no máximo 2 arquivos por ano; Senado faz 1 chamada por senador

## Entrega (28/10/2026)
- Saída: `data/proposicoes-camara.json` e `data/proposicoes-senado.json`, uma linha por (parlamentar, proposição)
- Termos de homenagem e tipos legislativos em `config/categorias-proposicao.json` (CA2)
- Câmara: autor = `ordemAssinatura` 1; demais = coautor. Autores não-deputados (Executivo, comissões) ignorados
- Senado: autoria vem como texto; autor = primeiro nome do texto
- Ementa com espaços/tabulações normalizados
