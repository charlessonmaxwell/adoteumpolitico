# Story 1.0 — Setup do repositório

**Épico:** 1 · **Status:** Concluída (27/10/2026) · **Depende de:** —

## Objetivo
Criar a base do projeto para que as próximas stories só adicionem código.

## Tarefas
1. Repositório público no GitHub `meu-politico-de-estimacao`
2. Node 22 + TypeScript (strict) + pnpm
3. Estrutura de pastas:
   ```
   pipeline/   coleta, validação, normalização, agregação
   site/       Astro
   data/       saída tratada (gitignored no main; publicada na branch `data`)
   tests/
   ```
4. Vitest para testes; ESLint + Prettier
5. Workflow GitHub Actions de CI: lint + testes em todo push
6. README com propósito do projeto e princípio de neutralidade
7. Copiar a pasta `bmad/` para o repositório

## Critérios de aceite
- CA1: `pnpm test` e `pnpm lint` rodam sem erro em repositório limpo
- CA2: CI roda em push e aparece verde no GitHub
- CA3: nenhuma credencial no repositório (`.env` no `.gitignore`)
