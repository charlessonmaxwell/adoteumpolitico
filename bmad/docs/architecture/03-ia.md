# Uso de IA

## Princípio
IA só onde texto fixo não resolve. Métricas numéricas usam modelos de frase (custo zero).

## Usos
| Uso | Entrada | Saída | Volume estimado |
|---|---|---|---|
| Resumo popular de proposição | Ementa oficial | 1–2 frases sem termo técnico | Histórico: ~10–20 mil (2023–2026, só PL/PLP/PEC/MPV/PDL); depois ~300–600/mês |
| Resumo de votação | Descrição + ementa | 1 frase "o que estava em jogo" | ~50/mês |
| Etiqueta de impacto (épico 6) | Ementa + nota técnica oficial (PDF), quando houver | Etiqueta objetiva + fonte + nível de confiança | ~2–3 proposições/mês |

## Regras
- Processa **só itens novos** (cache por ID): o histórico é pago uma única vez
- Prompt proíbe adjetivos e juízo de valor; saída validada por regras (lista de palavras proibidas: "bom", "ruim", "contra o povo" etc.)
- Toda saída de IA é marcada no site como "resumo gerado automaticamente" com link para o texto oficial

## Épico 6 — fluxo com trava
```
Proposições do mês (filtro por palavras-chave)
   → confirmação da lista (issue mensal no GitHub, ~5 min)
   → IA gera etiqueta
        ├─ fonte oficial com valor explícito + confiança alta → publica automaticamente
        └─ ambígua / sem fonte → issue de revisão → publica após aprovação
```
Reporte de erro com 3+ reportes → etiqueta ocultada até revisão.
